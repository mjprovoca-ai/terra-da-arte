# Terra da Arte

Museu digital vivo.

**Uma obra. Cinco segundos. Nunca mais.**

Experiência efêmera diária combinando legado artístico mundial + IA generativa.

## Stack

- Next.js (App Router) + TypeScript + Tailwind
- Supabase (Auth + Postgres + Storage)
- Google Gemini
- Deploy: Vercel

## Experiência do Dia

1. Imersão profunda no artista do dia
2. Três palavras + sensação → poema IA
3. Obra única por 5 segundos (anti-print)
4. Desaparece para sempre
